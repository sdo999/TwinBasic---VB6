# 《魔法门之英雄无敌》风格的消息生成器

该工具有助于创建复制《魔法门之英雄无视觉敌II/III》视频游戏风格的消息。我做这个只是为了好玩，因为我喜欢HoMM II和III以及他们的消息风格。

尝试一下：[在线生成HoMM风格消息] ( https://alexeisergienko.github.io/homm3-messages/ )

＃＃适合

在文本字段中输入需要的文本，选择HoMM第二部分或第三部分的样式，然后附加选择功能（框颜色、善/恶主题、按钮、阴影）。

新图片立即在右侧生成。您可以在此进行屏幕截图或使用左下角的按钮下载生成的图片。

##支持的角色

* 拉丁语、西里尔语、波兰语、匈牙利语字母
*数字
* ASCII 特殊字符
* 中文/繁體（By 高保洪 QQ 127644712 ）

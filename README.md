# 《魔法门之英雄无敌》风格的消息生成器

该工具有助于创建复制《魔法门之英雄无敌 II/III》视频游戏视觉风格的消息。我做这个只是为了好玩，因为我喜欢 HoMM II 和 III 以及他们的消息风格。

尝试一下：[在线生成HoMM风格消息] ( https://alexeisergienko.github.io/homm3-messages/ )

＃＃用法

在文本字段中输入所需的文本，选择 HoMM 第二部分或第三部分的视觉风格，然后选择附加功能（框颜色、善/恶主题、按钮、阴影）。

新图像立即在右侧生成。您可以对其进行屏幕截图或使用左下角的按钮下载生成的图像。

##支持的字符

*拉丁语、西里尔语、波兰语、匈牙利语字母
*数字
* ASCII 特殊字符
